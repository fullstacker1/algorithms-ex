# Curso de Recursividad

Un curso completo de recursividad para estudiantes de programación principiantes, con enfoque pedagógico y práctico.

## 📚 Contenido

### Lección 1: El Concepto de Recursividad
- Qué es recursividad
- Caso base y caso recursivo
- Ejemplos: contar atrás, factorial, suma natural, Fibonacci, reversa
- **10 ejercicios** de práctica

### Lección 2: Metodología para Analizar Problemas
- Framework de 4 pasos
- Identificación de casos base
- Pruebas manuales
- Errores comunes y debugging
- **10 ejercicios** de análisis

### Lección 3: Recursión con Strings
- Manipulación de texto
- Contar, eliminar, reemplazar caracteres
- Palíndromos
- Capitalización
- **10 ejercicios** de strings

### Lección 4: Recursión con Arrays
- Recorrido con índice
- Búsqueda, filtrado, transformación
- Aplanamiento
- **10 ejercicios** con arrays

### Lección 5: Divide y Vencerás
- Búsqueda binaria
- Merge sort
- Array rotados
- Problemas de división
- **10 ejercicios** avanzados

### Lección 6: Backtracking
- Técnica de exploración y retroceso
- Subsets, permutaciones, combinaciones
- Paréntesis válidos
- Problems combinatoriales
- **10 ejercicios** de backtracking

## 🎯 Características

- ✅ 60+ ejercicios con soluciones detalladas
- ✅ Enfoque pedagógico paso a paso
- ✅ Visualizaciones de pila de llamadas
- ✅ Análisis de problemas con framework sistemático
- ✅ Ejemplos de código JavaScript
- ✅ Navegación completa entre lecciones

## 🚀 Cómo Empezar

1. Abre `index.html` en tu navegador
2. Comienza con la Lección 1
3. Resuelve los ejercicios de cada lección
4. Avanza secuencialmente

Cada lección incluye:
- Explicación teórica
- Ejemplos con análisis detallado
- Visualizaciones
- 10 ejercicios con pistas y soluciones

## 💡 Metodología

1. **Comprensión antes de código**: Explicamos el "por qué" antes del "cómo"
2. **Progresión gradual**: Cada lección basa sobre la anterior
3. **Mucha práctica**: 10 ejercicios por tema
4. **Visualización**: Pila de llamadas y árboles de recursión
5. **Framework sistemático**: Pasos claros para analizar cualquier problema

## 📖 Para Estudiantes

- Preparación para entrevistas técnicas

## 🎓 Filosofía de Enseñanza

La recursividad es una forma de pensar, no solo un concepto técnico. Por eso:
- Usamos analogías del mundo real
- Mostramos el "ingrediente secreto" de cada problema
- Progresamos de simple a complejo
- Incluimos muchos ejemplos visuales
