Lección 4: Recursión con Arrays

Procesando secuencias de datos de forma recursiva

Nivel Intermedio 50 minutos estimados

¿Por qué Recursión con Arrays?

Los arrays (arreglos) son estructuras lineales perfectas para la recursión. Al igual que con los strings, podemos procesar un array mirando el primer elemento y luego recursivamente procesando el resto.

Analogía: La Línea de Producción

Imagina una línea de ensamblaje donde cada trabajador toma un producto, le hace una operación, y pasa el resto de la línea al siguiente trabajador. El primer trabajador ve el elemento 0 y pasa la fila sin ese elemento. El último trabajador recibe una fila vacía y simplemente devuelve el resultado final.

Estrategia General

El Patrón de Índice

La forma más común de recursión con arrays usa un parámetro índice que nos dice qué posición estamos procesando:

  1. Caso base: Cuando el índice llega al final del array (índice >= array.length)
  2. Caso recursivo: Procesamos el elemento en el índice actual, luego llamamos recursivamente con índice + 1
  3. Combinación: Combinamos el resultado del elemento actual con el resultado del resto del array

Ejemplo 1: Encontrar el Máximo

Dado un array de números, encontrar el valor máximo usando recursión.

JavaScript - Máximo Recursivo
function encontrarMaximo(arr, indice = 0) {
    // Caso base: si llegamos al final, devolvemos -Infinity
    if (indice === arr.length) {
        return -Infinity;
    }
    
    // Caso recursivo: máximo entre elemento actual y el máximo del resto
    const maxDelResto = encontrarMaximo(arr, indice + 1);
    return Math.max(arr[indice], maxDelResto);
}

// Ejemplo: encontrarMaximo([3, 7, 2, 9, 1])
// - Comparar 3 con max([7,2,9,1]) = 9 → resultado: 9
// - Comparar 7 con max([2,9,1]) = 9 → resultado: 9
// - Comparar 2 con max([9,1]) = 9 → resultado: 9
// - Comparar 9 con max([1]) = 1 → resultado: 9
// - Comparar 1 con max([]) = -Infinity → resultado: 1
// Resultado final: 9

Visualización de la Recursión

encontrarMaximo([3,7,2,9,1], 0) = max(3, 9) = 9
encontrarMaximo([7,2,9,1], 1) = max(7, 9) = 9
encontrarMaximo([2,9,1], 2) = max(2, 9) = 9
encontrarMaximo([9,1], 3) = max(9, 1) = 9
encontrarMaximo([1], 4) = max(1, -∞) = 1
encontrarMaximo([], 5) = -∞

Ejemplo 2: Suma de Elementos

Calcular la suma de todos los elementos en un array.

JavaScript - Suma Recursiva
function sumaArray(arr, indice = 0) {
    // Caso base: array vacío o fin del array
    if (indice === arr.length) {
        return 0;
    }
    
    // Caso recursivo: elemento actual + suma del resto
    return arr[indice] + sumaArray(arr, indice + 1);
}

// Ejemplo: sumaArray([1, 2, 3, 4])
// 1 + sumaArray([2,3,4], 1)
// 1 + 2 + sumaArray([3,4], 2)
// 1 + 2 + 3 + sumaArray([4], 3)
// 1 + 2 + 3 + 4 + sumaArray([], 4)
// 1 + 2 + 3 + 4 + 0 = 10

Ejemplo 3: Invertir Array

Devolver un nuevo array con los elementos en orden inverso.

JavaScript - Invertir Array Recursivo
function invertirArray(arr) {
    // Caso base: array vacío o un solo elemento
    if (arr.length <= 1) {
        return arr;
    }
    
    // Caso recursivo: último elemento + invertir el resto (sin último)
    const ultimo = arr[arr.length - 1];
    const resto = arr.slice(0, -1);
    return [ultimo].concat(invertirArray(resto));
}

// Variante usando índices (más eficiente):
function invertirArrayIndice(arr, inicio = 0, fin = arr.length - 1) {
    if (inicio >= fin) {
        return arr.slice(); // Devolver copia
    }
    
    const resultado = arr.slice();
    [resultado[inicio], resultado[fin]] = [resultado[fin], resultado[inicio]];
    
    // Invertir el interior recursivamente
    invertirArrayIndice(resultado, inicio + 1, fin - 1);
    return resultado;
}

// Ejemplo: invertirArray([1, 2, 3, 4])
// [4] + invertirArray([1,2,3])
// [4] + [3] + invertirArray([1,2])
// [4] + [3] + [2] + invertirArray([1])
// [4] + [3] + [2] + [1]
// Resultado: [4, 3, 2, 1]

Ejemplo 4: Filtrar Elementos

Devolver un nuevo array con solo los elementos que cumplen una condición.

JavaScript - Filtrar Recursivo
function filtrarArray(arr, condicion, indice = 0) {
    // Caso base: fin del array
    if (indice === arr.length) {
        return [];
    }
    
    // Caso recursivo: procesar elemento actual
    const restoFiltrado = filtrarArray(arr, condicion, indice + 1);
    
    if (condicion(arr[indice])) {
        return [arr[indice]].concat(restoFiltrado);
    } else {
        return restoFiltrado;
    }
}

// Ejemplo: filtrar pares
const esPar = n => n % 2 === 0;
filtrarArray([1, 2, 3, 4, 5, 6], esPar);
// esPar(1)? no → filtrarArray([2,3,4,5,6], 1)
// esPar(2)? sí → [2] + filtrarArray([3,4,5,6], 2)
// esPar(3)? no → [2] + filtrarArray([4,5,6], 3)
// esPar(4)? sí → [2] + [4] + filtrarArray([5,6], 4)
// esPar(5)? no → [2,4] + filtrarArray([6], 5)
// esPar(6)? sí → [2,4] + [6] + filtrarArray([], 6)
// Resultado: [2, 4, 6]

Ejemplo 5: Contar Ocurrencias

Contar cuántas veces aparece un valor específico en un array.

JavaScript - Contar Ocurrencias Recursivo
function contarOcurrencias(arr, valor, indice = 0) {
    // Caso base: fin del array
    if (indice === arr.length) {
        return 0;
    }
    
    // Caso recursivo: contar actual + contar en el resto
    const coincidenciaActual = (arr[indice] === valor) ? 1 : 0;
    return coincidenciaActual + contarOcurrencias(arr, valor, indice + 1);
}

// Ejemplo: contarOcurrencias([1, 2, 3, 2, 4, 2], 2)
// (1==2?0:1) + contarOcurrencias([2,3,2,4,2], 2, 1)
// 0 + (2==2?1:1) + contarOcurrencias([3,2,4,2], 2, 2)
// 0 + 1 + (3==2?0:1) + contarOcurrencias([2,4,2], 2, 3)
// 0 + 1 + 0 + (2==2?1:1) + contarOcurrencias([4,2], 2, 4)
// 0 + 1 + 0 + 1 + (4==2?0:1) + contarOcurrencias([2], 2, 5)
// 0 + 1 + 0 + 1 + 0 + (2==2?1:1) + contarOcurrencias([], 2, 6)
// 0 + 1 + 0 + 1 + 0 + 1 + 0 = 3

Estrategia con Slice vs Índices

Diferencias Importantes

Usando slice/array.slice(): Crea un nuevo array en cada llamada. Más intuitivo pero menos eficiente en memoria (O(n²) en espacio debido a copias).

Usando índice: No crea copias del array. Más eficiente (O(n) en tiempo, O(n) en pila). Recomendado para arrays grandes.

Análisis de Complejidad

Operación Complejidad Temporal Complejidad Espacial
Con índice (eficiente) O(n) O(n) - pila
Con slice (copias) O(n) O(n²) - copias + pila
Iterativo (comparación) O(n) O(1) - constante

Preguntas de Reflexión

¿Por qué usamos -Infinity como caso base en encontrarMáximo?

Porque cualquier número comparado con -Infinity será mayor, asegurando que el primer elemento válido se convierta en el máximo inicial.

¿Qué pasa si el array está vacío en encontrarMaximo?

Devuelve -Infinity. En la práctica, podrías querer lanzar un error o devolver undefined/null en vez de -Infinity.

¿Por qué la versión con índices es más eficiente en espacio que usar slice?

Porque slice crea una copia del array en cada llamada recursiva. Con n elementos, se crean n copias parciales, resultando en O(n²) espacio total. Con índices, solo pasamos referencias y un número, usando solo O(n) espacio en la pila.

¿Podríamos procesar arrays bidimensionales con este enfoque?

Sí, usando recursión anidada: un nivel para filas y otro para columnas. Útil para problemas como búsqueda en matrices o backtracking en grids.

💡 Aprendizajes Clave

  • Los arrays se pueden procesar recursivamente usando un índice que avanza hacia el final
  • El caso base típico es cuando el índice alcanza la longitud del array
  • Usar índices es más eficiente que slice para arrays grandes
  • La recursión con arrays sigue el mismo patrón: procesar elemento actual + recursión sobre el resto
