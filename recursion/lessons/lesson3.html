Lección 3: Recursión con Strings

Dominando la manipulación de texto de forma recursiva

Nivel Básico-Intermedio 40 minutos estimados

¿Por qué Strings?

Los strings son ideales para aprender recursión porque:

  • Son secuencias lineales (fáciles de recorrer)
  • Pueden dividirse en partes primero + resto o primero + medio + último
  • Son inmutables en JavaScript (cada "modificación" crea un string nuevo)
  • Tienen una propiedad length clara que sirve como caso base

Insight clave: Un string de longitud N puede verse como:

  • primerCaracter + subString(1)
  • subString(0, -1) + últimoCaracter
  • primerCaracter + subString(1, -1) + últimoCaracter

Ejemplo 1: Contar Caracteres Específicos

Contar cuántas veces aparece un carácter específico en un string.

Análisis

Entrada:

String str y carácter c

Salida:

Número de ocurrencias de c en str

Caso base:

String vacío → retornar 0

Paso recursivo:

Comparar primer carácter + contar en resto

JavaScript 
function contarCaracter(str, c) {
    // Caso base: string vacío
    if (str.length === 0) {
        return 0;
    }
    
    // ¿El primer carácter es el que buscamos?
    const coincide = (str[0] === c) ? 1 : 0;
    
    // Paso recursivo: coincidencia actual + contar en el resto
    return coincide + contarCaracter(str.slice(1), c);
}

// Ejemplos
console.log(contarCaracter("banana", "a")); // 3
console.log(contarCaracter("Hello World", "l")); // 3
console.log(contarCaracter("", "x")); // 0

Ejemplo 2: Remover Todos los Caracteres

Eliminar todas las ocurrencias de un carácter específico de un string.

Enfoque

¿Cómo eliminar un carácter?

No modificamos el string original, construimos uno nuevo.

Pregunta: Si queremos remover 'x' de "axbx", ¿cómo lo hacemos?

Si el primer carácter NO es 'x', lo mantenemos. Si SÍ es 'x', lo omitimos.

JavaScript 
function removerCaracter(str, c) {
    // Caso base: string vacío
    if (str.length === 0) {
        return "";
    }
    
    const primero = str[0];
    const resto = str.slice(1);
    
    // Si el primer carácter NO es el que queremos eliminar, lo conservamos
    if (primero !== c) {
        return primero + removerCaracter(resto, c);
    } else {
        // Si SÍ es, lo omitimos
        return removerCaracter(resto, c);
    }
}

// Versión más concisa
function removerCaracter2(str, c) {
    if (str.length === 0) return "";
    
    const primero = str[0];
    const resto = removerCaracter2(str.slice(1), c);
    
    return (primero === c) ? resto : primero + resto;
}

// Ejemplos
console.log(removerCaracter("banana", "a")); // "bnn"
console.log(removerCaracter("Hello World", " ")); // "HelloWorld"
console.log(removerCaracter("Mississippi", "s")); // "Miiippi"

Ejemplo 3: Reemplazo Recursivo

Reemplazar todas las ocurrencias de un carácter por otro.

JavaScript 
function reemplazar(str, buscar, reemplazarCon) {
    // Caso base
    if (str.length === 0) {
        return "";
    }
    
    const primero = str[0];
    const resto = reemplazar(str.slice(1), buscar, reemplazarCon);
    
    // Si coincide, reemplazar; si no, mantener
    if (primero === buscar) {
        return reemplazarCon + resto;
    } else {
        return primero + resto;
    }
}

// Ejemplos
console.log(reemplazar("hello", "l", "x")); // "hexxo"
console.log(reemplazar("banana", "a", "o")); // "bonono"
console.log(reemplazar("123-456-7890", "-", "")); // "1234567890"

Ejemplo 4: Primera Mayúscula en Cada Palabra

Convertir la primera letra de cada palabra a mayúscula.

Desafío

Necesitamos detectar el inicio de una palabra. Una palabra comienza después de un espacio o al inicio del string.

JavaScript 
function capitalizeWords(str, indice = 0, anteriorEsEspacio = true) {
    // Caso base: fin del string
    if (indice >= str.length) {
        return "";
    }
    
    const charActual = str[indice];
    let nuevoChar = charActual;
    
    // Si el carácter anterior era espacio, convertir a mayúscula
    if (anteriorEsEspacio && charActual !== ' ') {
        nuevoChar = charActual.toUpperCase();
    }
    
    // Determinar si el próximo carácter será después de un espacio
    const proximoAnteriorEsEspacio = (charActual === ' ');
    
    // Recursión: procesar resto del string
    return nuevoChar + capitalizeWords(str, indice + 1, proximoAnteriorEsEspacio);
}

// Versión más simple sin índice (procesando caracteres)
function capitalizeWords2(str) {
    // Caso base
    if (str.length === 0) return "";
    
    // Procesar primer carácter
    const primero = str[0];
    const resto = str.slice(1);
    
    const esInicioPalabra = (primero !== ' ' && (resto.length === 0 || str[1] === ' '));
    
    let nuevoPrimero = primero;
    if (esInicioPalabra) {
        nuevoPrimero = primero.toUpperCase();
    }
    
    return nuevoPrimero + capitalizeWords2(resto);
}

// Ejemplos
console.log(capitalizeWords("hola mundo")); // "Hola Mundo"
console.log(capitalizeWords("  espacios  extra  ")); // "  Espacios  Extra  "

Ejemplo 5: Eliminar Caracteres Consecutivos Duplicados

Dado un string, eliminar caracteres duplicados consecutivos.

Problema

"aaabbbccc" → "abc"

"Hello" → "Helo" (doble 'l' → una 'l')

  • Caso base: string vacío o de 1 carácter (no hay duplicados)
  • Lógica: Comparar primer y segundo carácter
  • Si son iguales: omitir el primer carácter, mantener el segundo
  • Si son diferentes: mantener el primer carácter
    • JavaScript 
    function eliminarDuplicadosConsecutivos(str) {
    // Caso base: 0 o 1 carácter
    if (str.length <= 1) {
        return str;
    }
    
    const primero = str[0];
    const segundo = str[1];
    const resto = str.slice(1);
    
    // Si primer == segundo, omitimos el primero
    if (primero === segundo) {
        return eliminarDuplicadosConsecutivos(resto);
    } else {
        // Si son diferentes, mantenemos el primero
        return primero + eliminarDuplicadosConsecutivos(resto);
    }
}

// Ejemplos
console.log(eliminarDuplicadosConsecutivos("aaabbbccc")); // "abc"
console.log(eliminarDuplicadosConsecutivos("Hello")); // "Helo"
console.log(eliminarDuplicadosConsecutivos("a")); // "a"
console.log(eliminarDuplicadosConsecutivos("")); // ""

    Aprendizajes Clave de Esta Lección

    • Los strings pueden procesarse carácter por carácter de forma recursiva.
    • El caso base típico es str.length === 0.
    • Tres patrones comunes: contar, eliminar, reemplazar.
    • Puedes usar un parámetro indice o slice para recorrer.
    • La recursión con strings es fundamental para problemas de parsing y validación.
