Lección 5: Divide y Vencerás

Dividir el problema para conquistar la solución

Nivel Intermedio-Avanzado 60 minutos estimados

¿Qué es Divide y Vencerás?

Divide y Vencerás (Divide and Conquer) es un paradigma algorítmico que consiste en resolver un problema:

  1. Dividir el problema en subproblemas más pequeños e independientes
  2. Vencer (resolver) los subproblemas recursivamente
  3. Combinar las soluciones de los subproblemas para formar la solución del problema original

Analogía: Ordenar una Baraja

Imagina que debes ordenar 1000 cartas. En lugar de ordenarlas todas a la vez (difícil), las divides en 2 mazos de 500, ordenas cada uno (más fácil), y luego fusionas los dos mazos ordenados en uno solo. Si 500 aún es mucho, divides cada mazo en 2 de 250, y así sucesivamente hasta llegar a 1 carta (que ya está ordenada).

Búsqueda Binaria: El Ejemplo Canónico

Dado un array ordenado, encontrar si un valor existe reduciendo el espacio de búsqueda a la mitad en cada paso.

JavaScript - Búsqueda Binaria Recursiva
function busquedaBinaria(arr, objetivo, inicio = 0, fin = arr.length - 1) {
    // Caso base 1: elemento no encontrado
    if (inicio > fin) {
        return -1;
    }
    
    // Calcular el punto medio
    const medio = Math.floor((inicio + fin) / 2);
    
    // Caso base 2: elemento encontrado
    if (arr[medio] === objetivo) {
        return medio;
    }
    
    // Caso recursivo: buscar en la mitad correspondiente
    if (objetivo < arr[medio]) {
        // Buscar en la mitad izquierda
        return busquedaBinaria(arr, objetivo, inicio, medio - 1);
    } else {
        // Buscar en la mitad derecha
        return busquedaBinaria(arr, objetivo, medio + 1, fin);
    }
}

// Ejemplo: buscar 5 en [1, 3, 5, 7, 9, 11, 13]
// medio = 3, arr[3] = 7, 5 < 7 → buscar en [1,3,5]
// medio = 1, arr[1] = 3, 5 > 3 → buscar en [5]
// medio = 2, arr[2] = 5, 5 == 5 → encontrado en índice 2

Análisis de Complejidad

Ecuación de Recurrencia: T(n) = T(n/2) + O(1)

Explicación: Dividimos el problema a la mitad T(n/2) y hacemos trabajo constante O(1) para calcular el medio y comparar.

Profundidad del Árbol de Recursión

Tamaño n Divisiones Altura del Árbol
8 elementos 8 → 4 → 2 → 1 log₂(8) = 3
16 elementos 16 → 8 → 4 → 2 → 1 log₂(16) = 4
1024 elementos 1024 → 512 → ... → 1 log₂(1024) = 10
1,000,000 elementos 2²⁰ ≈ 1M → ... → 1 log₂(1M) ≈ 20

Comparación: Búsqueda Lineal vs Binaria

Algoritmo Complejidad Temporal Pasos para n=1,000,000 Requisito
Búsqueda Lineal O(n) ~1,000,000 pasos Array desordenado
Búsqueda Binaria O(log n) ~20 pasos Array ordenado

Ventaja: La búsqueda binaria es ~50,000 veces más rápida para 1 millón de elementos.

Merge Sort Conceptual

El algoritmo de ordenamiento por mezcla es la aplicación clásica de Divide y Vencerás.

JavaScript - Merge Sort (Conceptual)
function mergeSort(arr) {
    // Caso base: array de 0 o 1 elemento ya está ordenado
    if (arr.length <= 1) {
        return arr;
    }
    
    // DIVIDIR: dividir el array en dos mitades
    const medio = Math.floor(arr.length / 2);
    const izquierda = arr.slice(0, medio);
    const derecha = arr.slice(medio);
    
    // VENCER: ordenar cada mitad recursivamente
    const izquierdaOrdenada = mergeSort(izquierda);
    const derechaOrdenada = mergeSort(derecha);
    
    // COMBINAR: fusionar las dos mitades ordenadas
    return merge(izquierdaOrdenada, derechaOrdenada);
}

function merge(izq, der) {
    let resultado = [];
    let i = 0, j = 0;
    
    // Comparar y mezclar elementos en orden
    while (i < izq.length && j < der.length) {
        if (izq[i] < der[j]) {
            resultado.push(izq[i]);
            i++;
        } else {
            resultado.push(der[j]);
            j++;
        }
    }
    
    // Agregar elementos restantes
    return resultado.concat(izq.slice(i)).concat(der.slice(j));
}

// Ejemplo: mergeSort([38, 27, 43, 3, 9, 82, 10])
// DIVIDIR: [38,27,43,3] y [9,82,10]
// DIVIDIR: [38,27] y [43,3] | [9,82] y [10]
// DIVIDIR: [38] [27] [43] [3] [9] [82] [10]
// VENCER: [27,38] [3,43] | [9,82] [10]
// VENCER: [3,27,38,43] | [9,10,82]
// COMBINAR: [3,9,10,27,38,43,82]

Complejidad Merge Sort: T(n) = 2T(n/2) + O(n)

Resultado: O(n log n) - óptimo para comparación-based sorting

Patrón General Divide y Vencerás

Plantilla Recursiva

function divideYVenceras(problema) {
    // 1. CASO BASE: problema lo suficientemente pequeño
    if (esTrivial(problema)) {
        return resolverDirectamente(problema);
    }
    
    // 2. DIVIDIR: dividir en subproblemas
    const subproblemas = dividir(problema);
    
    // 3. VENCER: resolver cada subproblema recursivamente
    const soluciones = [];
    for (const sub of subproblemas) {
        soluciones.push(divideYVenceras(sub));
    }
    
    // 4. COMBINAR: fusionar soluciones
    return combinar(soluciones);
}

Ejemplos Clásicos

  • Búsqueda Binaria: Divide en 1 subproblema de tamaño n/2
  • Merge Sort: Divide en 2 subproblemas de tamaño n/2
  • Quick Sort: Divide en 2 subproblemas (pivote divide elementos)
  • Multiplicación Karatsuba: Divide multiplicación en submultiplicaciones
  • FFT (Transformada Rápida): Divide polinomios en pares/impares

Preguntas de Reflexión

¿Por qué la búsqueda binaria requiere que el array esté ordenado?

Porque la decisión de ir a la izquierda o derecha depende de que todos los elementos a la izquierda sean menores y todos a la derecha sean mayores. Sin orden, no podemos descartar la mitad del array.

¿Cuál es la altura máxima del árbol de recursión para un array de tamaño n?

log₂(n), porque dividimos por 2 en cada nivel. Para n=1,000,000, la altura es ~20, lo que significa un límite de recursión muy seguro.

¿Por qué Merge Sort es más eficiente que algoritmos cuadráticos como Bubble Sort?

Merge Sort es O(n log n) vs O(n²) de Bubble Sort. Para n=1000, n log n ≈ 10,000 vs n² = 1,000,000. La división estratégica evita comparaciones innecesarias.

¿Qué pasa si intentamos búsqueda binaria en un array desordenado?

Podría no encontrar elementos que existen, o encontrar resultados incorrectos. El algoritmo depende de la propiedad de orden para descartar la mitad del espacio de búsqueda.

💡 Aprendizajes Clave

  • Divide y Vencerás divide el problema en subproblemas independientes más pequeños
  • La búsqueda binaria logra O(log n) reduciendo el espacio a la mitad en cada paso
  • Merge Sort divide en 2, ordena recursivamente y combina en O(n log n)
  • Log n crece muy lentamente: incluso para miles de millones de elementos, solo necesitamos ~30 divisiones
