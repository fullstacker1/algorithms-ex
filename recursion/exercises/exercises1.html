Ejercicio 1 Fácil

Contador Personalizado

Crea una función recursiva contadorPersonalizado(inicio, fin) que imprima los números desde inicio hasta fin (inclusive).

Ejemplo:

Entrada: contadorPersonalizado(3, 7)

Salida: 3, 4, 5, 6, 7

Necesitas DOS casos base: cuando inicio > fin (no hacer nada) y cuando inicio === fin (imprimir solo ese número).

function contadorPersonalizado(inicio, fin) {
    // Caso base: si inicio es mayor que fin, no hacemos nada
    if (inicio > fin) {
        return;
    }
    
    console.log(inicio);
    
    // Paso recursivo: llamar con siguiente número
    contadorPersonalizado(inicio + 1, fin);
}

// Ejemplo: contadorPersonalizado(3, 7)
// Salida: 3, 4, 5, 6, 7
Ejercicio 2 Fácil

Suma de Dígitos

Escribe una función recursiva sumaDigitos(n) que calcule la suma de todos los dígitos de un número entero positivo.

Ejemplo:

Entrada: sumaDigitos(1234)

Salida: 10 (porque 1+2+3+4=10)

Usa el operador módulo (%) para obtener el último dígito y división entera (Math.floor o ~~) para eliminar el último dígito.

function sumaDigitos(n) {
    // Convertir a positivo si es negativo
    n = Math.abs(n);
    
    // Caso base: número de un dígito
    if (n < 10) {
        return n;
    }
    
    // Paso recursivo: último dígito + suma del resto
    return (n % 10) + sumaDigitos(Math.floor(n / 10));
}

// Ejemplos
console.log(sumaDigitos(1234)); // 10
console.log(sumaDigitos(999));  // 27
console.log(sumaDigitos(5));    // 5
Ejercicio 3 Fácil

Potencia con Recursividad

Implementa potencia(base, exponente) que calcule base^exponente usando recursividad. Asume exponente ≥ 0.

Ejemplo:

Entrada: potencia(2, 5)

Salida: 32

base^0 = 1 (caso base). base^exp = base × base^(exp-1).

function potencia(base, exponente) {
    // Caso base: cualquier número a la 0 es 1
    if (exponente === 0) {
        return 1;
    }
    
    // Paso recursivo: base * base^(exponente-1)
    return base * potencia(base, exponente - 1);
}

// Ejemplos
console.log(potencia(2, 5));  // 32
console.log(potencia(3, 3));  // 27
console.log(potencia(5, 0));  // 1
console.log(potencia(2, 10)); // 1024
Ejercicio 4 Fácil

Producto de Números

Crea productoRango(inicio, fin) que retorne el producto de todos los números enteros desde inicio hasta fin (inclusive).

Ejemplo:

Entrada: productoRango(2, 5)

Salida: 120 (porque 2×3×4×5=120)

Similar al factorial, pero el inicio no siempre es 1. Caso base: inicio > fin retorna 1.

function productoRango(inicio, fin) {
    // Caso base: rango vacío
    if (inicio > fin) {
        return 1;
    }
    
    // Caso base: un solo número
    if (inicio === fin) {
        return inicio;
    }
    
    // Paso recursivo: inicio * producto del resto
    return inicio * productoRango(inicio + 1, fin);
}

// Ejemplos
console.log(productoRango(2, 5));  // 120
console.log(productoRango(1, 5));  // 120 (igual que factorial(5))
console.log(productoRango(3, 3));  // 3
Ejercicio 5 Fácil

Cuenta Vocales

Escribe contarVocales(str) que retorne el número de vocales (a, e, i, o, u) en un string, usando recursividad.

Ejemplo:

Entrada: contarVocales("recursividad")

Salida: 5 (e, u, i, a, ? revisa)

Revisa el primer carácter con un conjunto de vocales. Luego cuenta en el resto del string.

function contarVocales(str) {
    const vocales = 'aeiouAEIOU';
    
    // Caso base: string vacío
    if (str.length === 0) {
        return 0;
    }
    
    // Verificar primer carácter
    const primeraEsVocal = vocales.includes(str[0]) ? 1 : 0;
    
    // Paso recursivo: cuenta primera + resto del string
    return primeraEsVocal + contarVocales(str.slice(1));
}

// Ejemplos
console.log(contarVocales("recursividad")); // 5
console.log(contarVocales("Hola Mundo"));    // 4
console.log(contarVocales("xyz"));           // 0
console.log(contarVocales(""));              // 0
Ejercicio 6 Fácil

Invertir Array

Crea invertirArray(arr) que retorne un nuevo array con los elementos en orden inverso usando recursividad.

Ejemplo:

Entrada: invertirArray([1, 2, 3, 4])

Salida: [4, 3, 2, 1]

Último elemento + invertir del resto. Caso base: array vacío retorna array vacío.

function invertirArray(arr) {
    // Caso base: array vacío
    if (arr.length === 0) {
        return [];
    }
    
    // Tomar último elemento + invertir el resto
    const ultimo = arr[arr.length - 1];
    const resto = arr.slice(0, -1);
    
    return [ultimo].concat(invertirArray(resto));
}

// Versión más elegante (sin slice)
function invertirArray2(arr) {
    if (arr.length === 0) return [];
    return [arr.pop()].concat(invertirArray2(arr));
}

// Ejemplos
console.log(invertirArray([1, 2, 3, 4])); // [4, 3, 2, 1]
console.log(invertirArray(['a', 'b', 'c'])); // ['c', 'b', 'a']
console.log(invertirArray([])); // []
Ejercicio 7 Fácil

Múltiplos de 3

Escribe contarMultiplos3(n) que cuente cuántos múltiplos de 3 hay desde 1 hasta n (inclusive) usando recursividad.

Ejemplo:

Entrada: contarMultiplos3(10)

Salida: 3 (3, 6, 9)

¿Es n divisible por 3? (n % 3 === 0). Luego cuenta desde 1 hasta n-1 recursivamente.

function contarMultiplos3(n) {
    // Caso base: no hay números positivos
    if (n <= 0) {
        return 0;
    }
    
    // ¿Es n múltiplo de 3?
    const esMultiplo = (n % 3 === 0) ? 1 : 0;
    
    // Paso recursivo: contar n si es múltiplo + contar hasta n-1
    return esMultiplo + contarMultiplos3(n - 1);
}

// Ejemplos
console.log(contarMultiplos3(10)); // 3
console.log(contarMultiplos3(15)); // 5
console.log(contarMultiplos3(2));  // 0
console.log(contarMultiplos3(3));  // 1
Ejercicio 8 Medio

Números Pares en un Array

Escribe contarPares(arr, indice) que cuente cuántos números pares hay en un array usando recursividad.

Ejemplo:

Entrada: contarPares([1, 2, 3, 4, 5, 6], 0)

Salida: 3 (2, 4, 6)

Usa un parámetro indice para recorrer el array. Caso base: indice >= arr.length.

function contarPares(arr, indice) {
    // Caso base: fin del array
    if (indice >= arr.length) {
        return 0;
    }
    
    // ¿Es el elemento actual par?
    const esPar = (arr[indice] % 2 === 0) ? 1 : 0;
    
    // Paso recursivo: cuenta actual + resto del array
    return esPar + contarPares(arr, indice + 1);
}

// Función envoltorio para no pasar índice manualmente
function contarParesFacil(arr) {
    return contarPares(arr, 0);
}

// Ejemplos
console.log(contarParesFacil([1, 2, 3, 4, 5, 6])); // 3
console.log(contarParesFacil([2, 4, 6, 8]));        // 4
console.log(contarParesFacil([1, 3, 5]));           // 0
Ejercicio 9 Medio

Palindrome Checker

Crea esPalindrome(str) que determine si un string es un palíndromo (se lee igual hacia adelante y atrás).

Ejemplo:

Entrada: esPalindrome("reconocer")

Salida: true

Compara el primer y último carácter. Si son iguales, verifica el substring interno. Casos base: string vacío o de 1 carácter es palindrome.

function esPalindrome(str) {
    // Normalizar: quitar espacios y convertir a minúsculas
    str = str.toLowerCase().replace(/\s/g, '');
    
    // Caso base: string vacío o de 1 carácter
    if (str.length <= 1) {
        return true;
    }
    
    // Comparar primer y último carácter
    if (str[0] !== str[str.length - 1]) {
        return false;
    }
    
    // Paso recursivo: verificar substring interno
    return esPalindrome(str.slice(1, -1));
}

// Ejemplos
console.log(esPalindrome("reconocer"));    // true
console.log(esPalindrome("ana"));           // true
console.log(esPalindrome("hola"));          // false
console.log(esPalindrome("A man a plan"));  // true (ignora espacios)
Ejercicio 10 Medio

Suma Acumulativa

Crea sumaAcumulativa(n) que calcule Σ(i=1 to n) de i usando recursividad (sin usar la fórmula n(n+1)/2).

Ejemplo:

Entrada: sumaAcumulativa(5)

Salida: 15 (1+2+3+4+5)

Similar a sumaNaturales. ¿Cuál es el caso base? ¿Cómo reduces n en cada llamada?

function sumaAcumulativa(n) {
    // Caso base
    if (n <= 0) {
        return 0;
    }
    
    // Paso recursivo: n + suma de los anteriores
    return n + sumaAcumulativa(n - 1);
}

// Bonus: versión con acumulador (tail recursion)
function sumaAcumulativaTail(n, acumulador = 0) {
    if (n <= 0) {
        return acumulador;
    }
    return sumaAcumulativaTail(n - 1, acumulador + n);
}

// Ejemplos
console.log(sumaAcumulativa(5));   // 15
console.log(sumaAcumulativa(10));  // 55
console.log(sumaAcumulativa(100)); // 5050
